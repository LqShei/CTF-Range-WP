## 知识点解析：PHP 伪协议与文件包含

### 1. 什么是文件包含漏洞 (LFI/RFI)？

文件包含是指程序在引入文件时，由于没有对文件名进行严格的过滤，导致攻击者可以控制包含的路径。

* **本地文件包含 (LFI)**：包含服务器本地文件。
* **远程文件包含 (RFI)**：包含远程服务器上的文件（通常需要 `allow_url_include` 开启）。

### 2. PHP 伪协议：`php://filter`

在本题中，直接访问 `index.php` 可能会导致代码直接在服务器端执行，而我们无法看到源代码。**`php://filter`** 是 PHP 中一种用于处理流的元封装器，可以在文件读取之前对内容进行筛选或编码。

#### 核心原理：

当结合 `include()` 或 `require()` 函数时，如果不使用编码，PHP 会尝试执行该文件的内容。如果我们想要查看源码（例如获取数据库配置、Flag等），就需要阻止 PHP 执行它。

### 3. 关键 Payload 解析

在本案例中，使用的 Payload 为：
`?file=php://filter/read=convert.base64-encode/resource=index.php`

* **`php://filter`**: 告诉 PHP 我们要使用过滤器。
* **`read=convert.base64-encode`**: 这是关键步骤。它告诉 PHP 在读取文件内容后，先将其转换为 **Base64 编码**。
* *作用*：由于 Base64 编码后的字符串不是合法的 PHP 代码，包含后不会被执行，而是会直接显示在页面上。


* **`resource=index.php`**: 指定要读取的目标文件名。

### 4. 解题通用流程

1. **观察参数**：发现 URL 中存在 `?file=xxx` 或 `?page=xxx` 等疑似文件包含的参数。
2. **尝试读取**：直接尝试读取 `index.php`。如果页面没变化或报错，说明代码被执行了。
3. **伪协议绕过**：使用 `php://filter` 对源码进行 Base64 编码读取。
4. **解码获取 Flag**：将得到的 Base64 密文通过工具（如 CyberChef 或 Python）进行解码，从而获取源码中的 Flag 或关键逻辑。
